# Synthetic CLI demonstration

Recorded inspection of JSON produced by the SOCpilot `policy_example` module.
The source tool is MIT-licensed; see the policy-verifier LICENSE.
No third-party footage, music or narration is included.

Input is a source-defined synthetic example with empty telemetry. The video shows
actual plan checks and repairs. No operational incident data, model calls or
response actions are used. Browser styling and text selection aid readability.

The recording is a read-only CLI report walkthrough. It does not demonstrate an
interactive response console or measure incident containment.
