01 / Principle

Generation is probabilistic.
Policy checks are reproducible.

SOCpilot maps a proposed response to a finite action catalog and checks three operational rule families. The verifier records each violation and repair without asking another model to infer compliance from prose.

02 / Method

One fixed protocol.
Every decision auditable.

  1. IncidentNormalized, anonymized package.
  2. ActionsFinite catalog of response actions.
  3. PolicyReviewed predicates with explicit scope.
  4. ProtocolFixed matrix, hashes, ledger, and denominators.
  5. ReplayAnalysis reproducible without rerunning the model.

03 / Evidence state

Deterministic replay

Preserved inputs and outputs allow policy decisions and aggregate reports to be recomputed offline.

Fixed before execution

Corpus, models, prompts, repeats, contrasts, failure policy, and stopping rules are bound by one protocol manifest.

Preserved model evidence

Of 4,800 primary evaluation cells over 400 incidents, 4,798 produced a plan. 2 responses failed parsing and are excluded from the plan denominator. Analysis replay uses preserved outputs, not new model calls. Public release remains blocked by privacy review.

04 / Synthetic demonstration

Inspect a proposal, its violations and its repair.

The library example checks an ordered action list against two declared rules. The recording shows actual CLI output with empty telemetry and no model calls or executed response actions.

Use fullscreen to inspect JSON fields, or read the transcript.

Read the transcript

The example declares a proposal to reimage a host and then isolate it. Its policy requires forensic collection before reimaging and prohibits isolation. The original proposal violates both rules.

The verifier removes isolation and inserts forensic collection before reimaging. The repaired list is collect_forensics, followed by reimage_host. Both example rules pass, and a second enforcement pass leaves the list unchanged.

This is a synthetic demonstration of plan verification. It does not measure model behavior, analyst benefit or incident containment. The browser displays the original CLI report with text selection for readability; the recording is not an interactive response console.
